# 2026 Robot Code

This is the repository for the 2026 FRC robot code built with WPILib.

## Overview

This project contains the control software for our 2026 FRC competition robot, developed using the WPI Robotics Library (WPILib).

## Prerequisites

- Java 17 or later
- WPILib 2026.x
- Gradle

## Getting Started

1. Clone this repository
2. Open the project in VS Code with the WPILib extension
3. Run `./gradlew build` to compile the code
4. Deploy to the robot with `./gradlew deploy`
5. (Optional) FRC Driver Station Auto launch with elastic. Please checkout the [WPILib Docs](https://docs.wpilib.org/en/stable/docs/software/driverstation/manually-setting-the-driver-station-to-start-custom-dashboard.html).

## Project Structure

- `src/main/java/frc/robot/` - Main robot code
- `src/main/java/frc/robot/subsystems/` - Subsystem implementations
- `src/main/java/frc/robot/commands/` - Command definitions
